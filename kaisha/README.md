# 会社観察(丸栄商事)

新潟市東区にある架空の食品卸「丸栄商事株式会社」を、ただ眺めるだけのブラウザゲームです。
操作はできません。社員37人がそれぞれの性格・家庭・人間関係を持って働き、チャットし、噂し、ミスをし、恋をし、辞めていきます。
会社の数字は毎日の出荷と月末の締めで動き、資金が尽きると倒産して終わります。

## 遊び方

- `kaisha/index.html` を Web サーバー経由で開く(Render や GitHub Pages で公開した場合は `/kaisha/` を開く)
- 上の「×1〜×60」で時間の速さ、「翌朝へ」で次の出社時刻まで進める
- 3Dの人をクリックすると社員情報(性格・人間関係・噂・最近の出来事)
- 右のタブ:社内チャット(個別メッセージも閲覧できる)、会話(立ち話)、掲示板、日報、業績、名簿、取引先、新聞
- 進み具合はブラウザに自動保存。「はじめから」で新しい顔ぶれになる

## ファイル

| ファイル | 役割 |
|---|---|
| `js/world.js` | 会社・社員・取引先・銀行の初期状態 |
| `js/sim.js` | 時間の進行、一日の予定、人の動き、会話、ふだんのチャット |
| `js/events.js` | 出来事・事件と、何日もかけて進む話の続き |
| `js/business.js` | 売上・原価・経費・資金繰り・月次決算・倒産 |
| `js/text/` | チャット・立ち話・新聞の文例 |
| `js/style.js` | 一人ひとりの口ぐせ・打ち方の癖 |
| `js/view3d.js` | three.js による3D表示 |
| `js/ui.js` | 社内ポータル風の画面 |
| `lib/` | three.js(MIT) |
