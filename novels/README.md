# 書庫(自作小説のアーカイブ)

自分で書いた小説をしまっておき、本のような体裁で読むためのページです。
HTML・CSS・JavaScript だけで動くので、`/novels/` を開くだけで使えます(Render や GitHub Pages で公開すると `https://…/novels/`)。

## できること

- **取り込む**:テキスト(`.txt` `.md`。UTF-8 / Shift_JIS / UTF-16 を自動で判別)と PDF。
  画面にファイルを落としても取り込めます。PDF は折り返しで切れた行をつなぎ直し、ノンブル(ページ番号)や柱を外して段落にもどします。
  文字が画像になっている PDF(スキャンしたもの)は読めません。
- **書く・直す**:題・著者・あらすじ・本文をその場で書けます。
- **読む**:縦書き/横書き、文字の大きさ、明朝/ゴシック、地の色(紙・白・墨)を切りかえられます。
  ページは左右のタップ・クリック、スワイプ、矢印キー、ホイールでめくれます。読みかけの位置は作品ごとに覚えています。
- **控え**:「控えを書き出す」で全作品を `library.json` に保存、「控えを戻す」で読みこみます。

作品はブラウザの中(IndexedDB)に保存されます。ほかの端末やブラウザとは共有されないので、ときどき控えを書き出しておいてください。

## 本文の書き方

| 書き方 | 表示 |
|---|---|
| `\|漢字《かんじ》` / `漢字《かんじ》` / `\|漢字(かんじ)` | ルビ |
| `《《ここ》》` | 傍点 |
| `第一章 …` `第3話` `序章` `プロローグ` `# 見出し` だけの行 | 見出し(目次に載り、章はページを改める) |
| `［＃改ページ］` | 改ページ |
| `＊＊＊` `◇` など記号だけの行 | 場面の区切り |

全角空白で字下げしていない原稿は、自動で一字下げます(かぎかっこで始まる行は下げません)。
縦書きでは、2桁までの数字と `!?` `!!` を縦中横にします。

## 誰かに読んでもらう(公開)

「控えを書き出す」で出てきた `library.json` を、この `novels/` フォルダに置いて公開すると、
ページを開いた人の書架にその作品が並びます(読むだけで、直したり消したりはできません)。

## ファイル

| ファイル | 役割 |
|---|---|
| `index.html` | 入り口 |
| `style.css` | 見た目 |
| `js/main.js` | 書架・扉・書く画面と、取り込み・控え |
| `js/reader.js` | 読む画面(段組みでページに割ってめくる) |
| `js/parse.js` | ルビ・見出しなどの記法を読みとる |
| `js/importer.js` | テキストと PDF から本文を取りだす |
| `js/store.js` | 保存(IndexedDB)と設定 |
| `lib/pdfjs/` | PDF を読むライブラリ pdf.js(Apache-2.0)。外部サービスに頼らず動くよう同梱。`cmaps-ja.json` は日本語フォントの文字対応表をまとめたもの |
