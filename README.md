# PIT WALL(レーシングドライバー・キャリア)

17歳のドライバーとして契約を結び、シーズンを重ねて頂点を目指すブラウザゲームです。
レースを自分で操作するのではなく、**作戦を決めて送り出し**、実況と順位の推移で結果を見届けます。

## 週末の流れ

1. **フリー走行**:ウイングとサスペンションを選んで走らせる(3回まで)。ドライバーの感想を手がかりにセットアップを合わせる
2. **予選の走り方**:一発に賭ける/確実にまとめる/タイヤを温存する
3. **決勝の作戦**:スタートのタイヤ、ピットの周回と替えるタイヤ、スティントごとの走り方、雨への対応、セーフティカーが出たときの動き
4. **送り出す**:計時タワー、順位の推移、実況でレースが進む(×1/×3/×10、結果へ飛ばすこともできる)

## 分野とクラス

| | ENTRY | TIER 1 | TIER 2 | TIER 3 | TOP |
|---|---|---|---|---|---|
| フォーミュラ | ジュニアカート | フォーミュラ・アカデミー | フォーミュラ・リージョナル | フォーミュラ・セカンド | グランプリ |
| GT・耐久 | | GT4 チャレンジ | GT3 スプリントカップ | 耐久 LMP2 | 耐久 ハイパーカー |
| ラリー | | ナショナルラリー | ラリー2 | | ワールドラリー |

- **耐久**:3人で1台。燃料補給は決まった周回ごと。タイヤを毎回替えるか2スティント使うか、自分が何スティント乗るか、マシンをどこまで攻めるかを決める。最終戦は24時間でポイント2倍
- **ラリー**:1台ずつステージのタイムを競う。ループごとにタイヤ・スペアの本数・攻め方を決める。グラベルの初日は選手権上位ほど先に走り、砂利を掃く役になる

シーズンが終わると、成績と評価に応じてオファーが届きます。チーム名・ドライバー名・コースはすべて架空です。
1シーズンはおよそ5〜8分。30〜60分ほどで一つのキャリアを遊べます(いつでも引退できます)。

## 遊び方(公開)

HTML・CSS・JavaScript だけで動きます。ビルドもインストールも要りません。
進行はブラウザの localStorage に自動で保存されます。

### Render

1. https://dashboard.render.com で **New +** → **Blueprint**
2. リポジトリ **thinline0924-cell/spritisland** を選ぶ
3. `render.yaml`(ブランチ `racing-career`)の **pitwall** を Apply する

### GitHub Pages

Settings → Pages で、Branch を `racing-career`、フォルダを `/ (root)` にして Save します。

### 手元で動かす

```
python3 -m http.server 8000
```
を実行して http://localhost:8000 を開きます(`index.html` を直接開いても動きます)。

## ファイル

- `js/data.js` シリーズ・タイヤ・サーキット・ラリーのデータ
- `js/circuit.js` サーキットのレース計算(タイヤの劣化、天候、ピット、セーフティカー、追い抜き)
- `js/rally.js` ラリーの計算(ループ、パンクとスペア、スーパーラリー、出走順)
- `js/career.js` シーズン・成長・オファー・保存
- `js/art.js` コース図や表紙の線画
- `js/ui.js` `js/weekend.js` `js/race.js` 画面
