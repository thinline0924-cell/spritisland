# 精霊の島(Spirit Island 一人用 3D ボードゲーム)

ボードゲーム「スピリット・アイランド」を題材にした、**ひとりで遊ぶ** ブラウザゲームです。
あなたは島に宿る精霊となり、島の人々(ダハン)と力を合わせて、海の向こうから来る侵略者を追い払います。
島はドット絵風の 3DCG で描かれ、回したり拡大したりしながら遊べます。

## 遊び方(いちばんかんたんな方法:GitHub Pages で公開)

このゲームは HTML・CSS・JavaScript だけでできているので、インストールは不要です。

1. GitHub でこのリポジトリを開く
2. 上のメニューの **Settings(設定)** → 左の **Pages** を開く
3. 「Build and deployment」の **Source** を「Deploy from a branch」にする
4. **Branch** を `main`、フォルダを `/ (root)` にして **Save**
5. 1〜2分待つと、ページ上部に `https://thinline0924-cell.github.io/spritisland/` のような URL が出るので、それを開く

スマホでも遊べます(縦向きなら、2本指で拡大すると島が見やすくなります)。

> 注意:`index.html` をパソコンでダブルクリックして直接開くと、ブラウザの安全のしくみ(ES モジュールの制限)で表示されません。
> GitHub Pages などの「Web サーバー」経由で開いてください。

## ルールのあらまし

- **勝ち**:恐怖カードを9枚集める。または恐怖レベルごとの条件(Ⅰ:侵略者全滅/Ⅱ:町と都市なし/Ⅲ:都市なし)を満たす
- **負け**:荒廃が尽きる/精霊の存在が島から消える/侵略者カードが尽きる(12枚=約11ターン)
- 1ターン:成長 → エネルギーを得てカードを選ぶ → 速いパワー → 侵略者(恐怖カード・荒らし・建設・探検)→ 遅いパワー
- 詳しいルールはゲーム内の「遊び方」(右上の丸いボタン)で読めます

精霊は2人、難易度は3段階(やさしい/ふつう/むずかしい)。はじめての人は「陽光をうつす大河」+「やさしい」がおすすめです。

## ファイルの役割

| ファイル | 役割 |
|---|---|
| `index.html` | 画面の骨組み |
| `style.css` | 見た目(紺とうす紫の夜明け前の色、ドット風フォント) |
| `js/main.js` | 入り口。島・3D表示・画面・ゲームをつなぐ |
| `js/data.js` | 地形・精霊・パワーカード・恐怖カード・侵略者カード・難易度のデータ |
| `js/boardgen.js` | 島の形と、土地どうしのとなり関係を作る |
| `js/game.js` | ルールの本体(ターンの流れ、荒らし・建設・探検、恐怖、荒廃、勝ち負け) |
| `js/board3d.js` | three.js による 3D 表示(ブロックの島・水面の映りこみ・月・森・ほたる・駒) |
| `js/ui.js` | パネル・手札・案内・ダイアログ |
| `lib/` | three.js(3D表示のライブラリ。MIT ライセンス)。ネットの外部サービスに頼らず動くよう同梱 |
