# DDP 試聴プレーヤー

CD マスターの **DDP(Disc Description Protocol 2.0)ファイルセット** を、そのまま試聴・確認するためのソフトです。
ブラウザだけで動き、インストールは要りません。ファイルはパソコンの中だけで読み込まれ、どこにも送信されません(オフラインでも動きます)。

## 使い方

**ウェブで使う**:https://claude.ai/artifact/6SrrRTikB8GLaSzG1TQsmB を開くだけで使えます(最初は公開した人だけが開けます。ほかの人に使ってもらうときは、ページの「共有」から共有してください)。
開いた直後はお試し用のサンプル(3曲)が読み込まれていて、そのまま再生できます。

**パソコンで使う**:

1. `ddp-player/index.html` をブラウザ(Chrome・Edge・Firefox・Safari)で開く
   - パソコンでダブルクリックして直接開いて大丈夫です(Web サーバーは要りません)
   - Render などで公開している場合は `https://<公開先>/ddp-player/` でも開けます
2. DDP のフォルダ(`DDPID`・`DDPMS`・`PQDESCR`・`IMAGE.DAT` などが入ったもの)を画面にドロップする
   または「フォルダを選ぶ」で選ぶ
   - ZIP で届いた DDP は、先に展開(解凍)してください
3. 曲をクリックすると、その曲の頭(INDEX 01)から再生します

### キー操作

| キー | 動き |
|---|---|
| スペース | 再生 / 一時停止 |
| ← / → | 5秒戻る / 進む(Shift を押しながらだと30秒) |
| ↑ / ↓ | 前の曲 / 次の曲 |
| 1〜9 | その番号の曲を再生 |
| Home | ディスクの最初へ |
| Esc | 停止(1曲目の頭に戻る) |

## できること

- **CD と同じ流れで再生**:IMAGE.DAT を先頭から曲間(プリギャップ)も含めてすき間なく再生します。
  プリギャップの中では、CD プレーヤーと同じく `INDEX 00` と曲の頭までの残り時間(`-00:02` など)を表示します
- **曲の一覧**:曲番号・CD-TEXT のタイトルとアーティスト・開始位置(MM:SS:FF)・長さ・プリギャップ・ISRC・ピークレベル
- **CD-TEXT**:日本語(MS-JIS / Shift_JIS)と英字(ISO-8859-1)に対応
- **チェックサムの照合**:`CHECKSUM.MD5` などの `.md5` ファイルがあれば、全ファイルの MD5 を計算して照合します。
  `<md5> *ファイル名`・`<md5>  ファイル名`・`MD5 (ファイル名) = <md5>`・`IMAGE.DAT.md5`(値だけ)の書き方に対応。
  計算は再生しながら裏で行い、CD 1枚分(約700MB)で10秒ほどです
- **ピークとクリップの確認**:曲ごとのピーク(dBFS)と、フルスケール(0 dBFS)のサンプル数を調べます
- **レベルメーター**:左右のピーク(dBFS)と OVER 表示。音量つまみの影響を受けない、素材そのもののレベルです
- **バイト順の自動判定**:リトルエンディアン / ビッグエンディアンを音の中身から判定します(手動で切りかえも可)
- **診断**:次のようなおかしな点を一覧で知らせます
  - DDPMS・PQDESCR の書式の乱れ、曲番号の飛び、曲の順番の逆転、INDEX 01 がない
  - 音声データがリードアウトより短い(足りない部分は無音で再生)
  - 4秒より短い曲、79:57 を超える長さ
  - ISRC・UPC/EAN(チェックデジット)の形式の誤り、DDPID と PQDESCR の UPC の食い違い
  - CD-TEXT の CRC の誤り、プリエンファシス・データトラックの印
- **1曲ずつ止める**:曲の終わりで止まります(曲ごとの確認用)

## 信頼性のための工夫

- IMAGE.DAT は全部をメモリに読み込まず、約0.37秒ずつ読みながら Web Audio にすき間なく並べて鳴らします。
  大きなファイルでも軽く、再生しながら検証できます
- 可能な環境では出力を CD と同じ 44.1kHz にします(できないときは画面の「出力」に変換していることを表示)
- タブが裏に回ったときは先読みを長くして、音切れを防ぎます
- ファイルが読めなくなったら(USB メモリを抜いたなど)再生を止めて知らせます
- 外部のライブラリやネット上のサービスを使っていません(MD5 も自前で実装し、Node.js の crypto と結果を照合するテストあり)
- DDPMS に書かれたファイル名が見つからないときは標準の名前(`PQDESCR`・`CDTEXT.BIN`・`*.DAT`)を探します。大文字・小文字の違いは区別しません

## 注意

- 試聴・確認のためのソフトです。ブラウザの音声処理を通すため、ビット単位で完全に同じ出力であることは保証しません
  (データそのものが正しいかどうかは、チェックサムの照合で確かめてください)
- プリエンファシス付きの曲は、ディエンファシスをかけずにそのまま再生します(診断に表示されます)
- 対応しているのは音楽 CD 用の DDP 2.0 です(DVD 用の DDP 2.1 などには対応していません)

## ファイルの役割

| ファイル | 役割 |
|---|---|
| `index.html` | 画面の骨組み |
| `style.css` | 見た目(ライト / ダーク両対応) |
| `js/ddp.js` | DDPID・DDPMS・PQDESCR・CD-TEXT・チェックサムファイルの読み取りとチェック、バイト順の判定 |
| `js/player.js` | 再生エンジン(Web Audio で少しずつ読みながら再生) |
| `js/md5.js` | MD5 の計算(少しずつデータを渡せる版) |
| `js/app.js` | ファイルの読み込み・検証・画面の表示・操作 |
| `js/sample.js` | お試し用のサンプル DDP をブラウザの中で作る(最初に自動で開く) |
| `tools/build-web.js` | ウェブ公開用に CSS と JavaScript を1つの HTML にまとめる(`node tools/build-web.js <出力ファイル>`) |
| `test/make-sample-ddp.js` | テスト用の DDP を作る(`node test/make-sample-ddp.js <フォルダ>`) |
| `test/run.js` | 読み取り部分のテスト(`node test/run.js`) |
| `test/e2e.js` | ブラウザでの動作テスト(Playwright が必要。`node test/e2e.js`) |

## テスト用の DDP を作って試す

```sh
cd ddp-player
node test/make-sample-ddp.js ./sample-ddp          # 日本語 CD-TEXT 付き、3曲
node test/make-sample-ddp.js ./sample-be --be       # ビッグエンディアン
```

できたフォルダを画面にドロップすると、3曲(サイン波の音)が並んで表示されます。
